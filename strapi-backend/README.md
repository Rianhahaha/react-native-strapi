# 🚀 Getting started with Strapi

### `install dependencies`

```
npm install

```
### `Setting the ENV`
you would want to create the env first. The template is in the env example file

### `Run Development Environment`


### `develop`
Start Strapi Application with Development Environtment, Run this command for developing.

```
npm run develop
# or
yarn develop

```
### `build`

Build the admin panel Strapi Application for a clean production build.

```
npm run build

```

### `start`

Start the built Strapi Application. Need to npm run build first tu execute this command. Run this command to Production

```
npm run start

```
